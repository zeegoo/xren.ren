# 境界角色素材

当前使用 anime（简笔动漫版）。realistic 保存上一版写实角色。

在 site 目录执行：
- node tools/switch-characters.cjs anime
- node tools/switch-characters.cjs anime-v2
- node tools/switch-characters.cjs realistic

切换后重新构建。各套素材均为 AI 生成，网页使用透明 WebP。
角色出现在首页境界卡片、目录页头、文章侧栏。更新时保持六个境界同名文件齐全。
anime 为六位独立外貌版：卷发圆脸、寸头方脸、侧分长脸、刺发护目镜、低马尾、灰白背头短胡须；金丹、化神、渡劫已重绘为统一的三头身比例，六人素材按人物实体高度归一（660px、脚底对齐）。anime-v2 保存重绘前的六人版本，anime-v1 保留更早一版。
