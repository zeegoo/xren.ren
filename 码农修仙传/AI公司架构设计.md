## 三个AI Agent

### 1. 策划Agent（mncxc-plan）
- **职责**：选题规划、大纲生成、内容排期管理
- **输入**：六大境界体系、文章填充状态、热点数据
- **输出**：选题推荐表、单篇大纲（待审核）
- **触发**：按需调用 / 每周自动规划

### 2. 创作Agent（mncxc-write）
- **职责**：根据审核通过的大纲撰写完整图文，直接写入 VitePress 文件
- **输入**：单篇大纲、六段式结构模板
- **输出**：完整Markdown图文（含mermaid图、代码块、术语对照表）
- **触发**：大纲审核通过后调用

### 3. 发行Agent（mncxc-publish）
- **职责**：VitePress站点同步、多平台格式适配、发布清单管理、数据回收
- **输入**：审核通过的完整图文
- **输出**：各平台适配内容、发布清单、数据报表
- **触发**：图文审核通过后调用

## 工作流程

```
 Week N
 ┌─────────────────────────────────────────────────────────┐
 │ Step 1  策划Agent → 扫描空壳文章 → 推荐下一篇 + 生成大纲   │
 │ Step 2  【用户审核大纲】 ← 人工节点①：确认方向、调整结构     │
 │ Step 3  创作Agent → 根据大纲写完整图文 → 写入 VitePress 文件 │
 │ Step 4  【用户审核优化】 ← 人工节点②：技术校对、风格调整      │
 │ Step 5  发行Agent → VitePress构建检查 + 多平台格式适配     │
 │ Step 6  用户确认发布 → 各平台分发                          │
 │ Step 7  发行Agent → 7天后回收数据 → 反馈策划Agent           │
 └─────────────────────────────────────────────────────────┘
              ↓ 数据驱动下一周选题优化
```

## 人机协作原则

| 环节 | 负责方 | 说明 |
|------|--------|------|
| 选题规划 | AI策划 | Agent按体系+数据推荐，用户拍板 |
| 大纲生成 | AI策划 | Agent产出，用户审核调整 |
| 正文撰写 | AI创作 | Agent写初稿，直接写入VitePress文件 |
| 配图制作 | AI创作 | mermaid图/架构图自动生成 |
| 技术校对 | 用户 | 核心技术准确性人工把关 |
| 站点同步 | AI发行 | VitePress构建检查 |
| 平台适配 | AI发行 | 格式转换自动完成 |
| 最终发布 | 用户 | 确认后分发 |
| 数据回收 | AI发行 | 自动回收+分析+反馈 |

## 调用方式

### 按需调用（单篇生产）
```
用户: "开始本周内容生产"
→ delegate_task 加载 mncxc-plan 技能 → 扫描空壳 → 生成大纲
→ 用户审核大纲
→ delegate_task 加载 mncxc-write 技能 → 写稿 → 写入VitePress
→ 用户审核优化
→ delegate_task 加载 mncxc-publish 技能 → 适配分发
```

### 定时任务（数据回收）
```
cronjob 每周日 → 发行Agent回收各平台数据 → 更新数据报表
cronjob 每周一 → 策划Agent根据数据 → 更新选题推荐
```
