## 写作规范

| 项目 | 要求 |
|------|------|
| 篇幅 | 3000-5000 字 |
| 语言 | 中文，技术术语保留英文原文 |
| 代码 | 带语言标注的代码块，关键行加注释 |
| 配图 | 用 mermaid 画架构图/流程图/时序图，至少 1 张 |
| 修仙类比 | 每个技术概念都有对应的修仙术语映射 |
| 语气 | 专业不枯燥，有江湖气但不尬，适当幽默 |
| 结构 | 六段式不可缺省 |

### 六段式结构（每篇必须包含）

1. **境界标识 + 修仙引入** — 修仙梗引入，2-3 句话
2. **硬核主体** — 技术知识讲解 + 代码 + mermaid 图
3. **修仙术语对照表** — 表格形式
4. **突破条件** — checklist 形式
5. **下期预告 + 互动** — 预告下一篇 + 互动话术
6. **落款** — 系列编号 + xren.ren 链接

## 选题原则

1. **体系优先**：严格按编号顺序填充，不跳跃
2. **元婴主场**：嵌入式/底层内容是差异化核心，重点投入
3. **70/30 配比**：70% 体系内选题，30% 热点选题引流
4. **修仙类比骨架**：每个选题必须有明确的修仙术语映射
5. **技术准确**：选题方向必须落在创作者技术能力范围内
