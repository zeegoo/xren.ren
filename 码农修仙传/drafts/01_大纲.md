### ② 硬核主体

#### 2.1 什么是炼气期？——凡人到修仙者的最小跨度

**核心知识点**：
- 炼气期的定义：能够独立编写并运行简单程序，理解变量、循环、函数的基本概念
- 它不是"精通"，而是"入门"——你能用代码解决小问题，但不能解决复杂问题
- 与凡人状态的区别：凡人面对电脑只能使用软件，炼气期能够"驱动"电脑执行自己的指令

**修仙类比**：
- 凡人 = 软件用户（只会用App，App坏了只能求助）
- 炼气期 = 灵气初感（能写代码，能命令电脑，但还很弱）
- 筑基期 = 内功初成（理解原理，知道为什么）

**代码示例**——用三行代码展示炼气期的标志能力：

```python
# 这三行代码，就是炼气期码农的"引气入体"
name = input("你叫什么？")        # 变量赋值 —— 控制一个"容器"
while name == "":                  # 循环判断 —— 重复执行逻辑
    print("名字不能为空！")
    name = input("重新输入：")
print(f"欢迎踏入码农修仙界，{name}")  # 函数调用 —— 使用工具
```

> 配文：变量、循环、函数——这三板斧，就是炼气期的全部修为。看起来简陋？凡人连这三板斧都没有。

#### 2.2 炼气期的灵根天赋——你从哪种语言入门？

**核心知识点**：
- 入门语言选择不影响长期上限，但影响初期修炼速度
- 常见"灵根"分类及修炼体验

**修仙类比**——灵根属性 vs 编程语言：

| 灵根属性 | 对应语言 | 修炼体验 | 典型门派 |
|---------|---------|---------|---------|
| 木灵根（亲和自然） | Python | 语法简洁，接近自然语言，修炼顺畅 | "Python派"——AI/数据方向 |
| 金灵根（锋锐直接） | C语言 | 直接接触内存指针，锋利但易伤自身 | "C派"——嵌入式/系统方向 |
| 火灵根（热情外放） | JavaScript | 动态灵活，所见即所得，浏览器即修炼场 | "前端派" |
| 土灵根（厚重扎实） | Java/C++ | 语法繁重但体系严谨，修炼慢但根基厚 | "工程派"——大厂后端 |
| 水灵根（流通万法） | Go/Rust | 现代设计，适合从其他灵根转修 | "转修派" |

**核心观点**：
- 不存在"最好的灵根"，只有"最合适的灵根"
- 创作者本人是金灵根（C/嵌入式），但建议初学者从木灵根（Python）入手
- 灵根不决定上限，决定的是前三个月的体验

**代码示例**——同一功能在不同灵根下的修炼差异（Hello World对比）：

```python
# 木灵根（Python）—— 一行引气
print("Hello, World!")
```

```c
// 金灵根（C）—— 需要引头文件、声明main、返回值
#include <stdio.h>
int main() {
    printf("Hello, World!\n");
    return 0;
}
```

> 配文：同样引气入体，木灵根一行，金灵根五行。但金灵根修的是根基，后期力量上限更高——这就是为什么元婴期（硬件底层）的主场，C语言是必修功法。

#### 2.3 炼气期的三个阶段——你修到哪一层了？

**核心知识点**：
炼气期内部细分为三个小阶段，对应编程入门的不同掌握程度。

**修仙类比**——炼气三层 vs 编程入门三阶段：

| 层次 | 修仙术语 | 编程状态 | 标志能力 | 还不会什么 |
|------|---------|---------|---------|-----------|
| 第一层 | 炼气初期·引气入体 | 写第一行代码 | 理解变量、print、input | 不会循环、不会函数 |
| 第二层 | 炼气中期·气行经脉 | 能写小逻辑 | 掌握循环(if/while)、函数定义 | 不会复杂算法、不会工程组织 |
| 第三层 | 炼气后期·气沉丹田 | 能做小项目 | 能组合多函数、处理文件、调API | 不懂底层原理、不会架构 |

**代码示例**——三个层次标志性代码段：

```python
# 炼气初期：引气入体
print("Hello")  # 能让电脑说话了

# 炼气中期：气行经脉——逻辑流转
for i in range(5):
    if i % 2 == 0:
        print(f"{i} 是偶数")  # 能控制逻辑流转了

# 炼气后期：气沉丹田——多函数协作
def read_scores(path):
    with open(path) as f:
        return [int(x) for x in f.readlines()]

def average(scores):
    return sum(scores) / len(scores)

scores = read_scores("scores.txt")
print(f"平均分：{average(scores)}")  # 能组合功法了
```

#### 2.4 炼气期码农的日常修炼——从练功到实战

**核心知识点**：
- 炼气期怎么修炼（学习路径）
- 练功 vs 实战的区别（做题 vs 做项目）

**修仙类比**：
- **练功**（做练习题）= 打坐运气，强化经脉，但不出山门
- **实战**（做小项目）= 与低阶妖兽搏杀，检验功法，赚取灵石
- 只练功不实战 = 修炼瓶颈（纸上谈兵，真题做得很溜，一写项目就卡）
- 只实战不练功 = 走火入魔（靠抄代码能堆出项目，但换个需求就懵）

**修炼路径建议**（炼气期90天修炼计划）：

| 时间 | 阶段 | 功法 | 实战 |
|------|------|------|------|
| 1-2周 | 引气入体 | 基本语法：变量、类型、运算 | 命令行小程序：计算器、猜数字 |
| 3-4周 | 气行经脉 | 控制流：if/else、while/for | 文本处理：统计词频、格式转换 |
| 5-8周 | 凝气成流 | 函数、模块、文件IO | 小工具：批量重命名文件、日志分析 |
| 9-12周 | 气沉丹田 | 综合应用 + Git + 调试 | 完整小项目：个人记账本、待办清单 |

#### 2.5 炼气期的常见心魔——新手为什么容易放弃

**核心知识点**：
炼气期放弃率最高（编程入门课的退课率通常超50%），核心心魔有三：

**修仙类比**——炼气期三大心魔：

| 心魔 | 修仙设定 | 编程现实 | 破解方法 |
|------|---------|---------|---------|
| 急躁心魔 | 刚引气就想筑基，功法没练好就抢秘籍 | 还没学好语法就想做大型项目 | 接受"前期就是枯燥"，90天不出关是正常的 |
| 比较心魔 | 看到别人筑基金丹，自惭形秽 | 看到大佬炫技，觉得自己没有天赋 | 修仙看根骨更看时间，别人只是比你早入门 |
| 畏难心魔 | 遇到第一个报错就觉得自己不适合 | `SyntaxError` 红字一出就想退坑 | 报错是修炼日常，越往后报错越多越正常 |

**代码示例**——报错就是修炼日常：

```python
# 炼气期最常见的报错三连
print("Hello)        # SyntaxError: 引气姿势错误
int("abc")          # ValueError: 灵气属性不匹配  
name + 123          # TypeError: 功法属性冲突

# 大佬的代码也报错，只是他们报的错更高级
# import tensorflow as tf  → CUDA_ERROR_NOT_INITIALIZED
# 你早晚会遇到的，别急。
```

> 配文：修仙之路，报错就是天劫的预演。连报错都遇不到，说明你还没修到那个层次。

### ④ 突破条件

**炼气期 → 筑基期 突破清单**：

- [ ] 能独立编写300行以上的程序，不需要抄教程
- [ ] 理解变量、循环、函数、文件IO，并能组合使用
- [ ] 完成至少1个完整小项目（从需求到调试到完成）
- [ ] 会用Git做版本管理（至少commit/push/pull）
- [ ] 遇到报错能不慌，会读错误信息、搜索、排查
- [ ] 开始意识到"光会写代码不够，需要懂原理"——这个意识就是筑基的引子

> 配文：当你写出第一个能用的程序，兴奋过后开始觉得"但好像还差什么"——恭喜，筑基的灵觉开始苏醒了。
